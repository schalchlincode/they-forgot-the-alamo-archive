The first Davy used cylinders and boxes as placeholders. This build replaces those shapes with a low-poly model featuring a face, hair, clothes, and a more human silhouette.

The project history includes close-up renders and a view at game size, where the model reads differently against the room. Both views are useful when comparing the model with the actual gameplay scale.
